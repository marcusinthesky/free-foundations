# Review a passage in reader order

Record the takeaway of each paragraph before looking at an earlier critique or tool output. Read both sides of a difficult join. Assess the contribution and evidence first, then decide whether a local edit will help.

| Passage | Editorial decision |
| --- | --- |
| “Two exercises illustrate these distinctions.” The next sentence gives the actual comparison. | Bring the comparison forward. Tell the reader which input changes and which outcome to watch. |
| “We use ranks. Ties receive their average rank.” | Keep the brief second sentence where the treatment of ties matters. Each sentence provides different information. |
| “The two allocations share an initial equilibrium.” A reader might interpret them as successive dates. | Keep the qualification that these are static counterfactuals. Removing it changes the interpretation. |
| Three paragraphs repeat the same disclaimer about causality. | Identify the inference an informed reader might draw at each occurrence. Establish the measurement boundary where it matters, then use its precise name. A standalone caption can need its own qualification. |
| “Why does the association arise?” The section establishes a cross-sectional association only. | Narrow the question to the observed comparison or lead with the finding. Retain a question that motivates an answer the section delivers. |
| “Consequently” joins a descriptive ranking to a claim about financial risk. | Identify the missing premise. Request supporting evidence or separate the claims. A stronger conjunction would strengthen the inference. |

## Inline feedback

Place the comment where the author can supply the missing idea.

```tex
% REVIEW: The roster grows here. Explain why the geometry calculation can
% use issuers with incomplete subsequent returns. Keep the ratio-specific
% observation counts distinct from the roster used to construct coordinates.
```

An alert from Vale supplies a location to inspect. A run of short sentences can support a definition, and a negative result can carry the paper's central contribution. Assess the passage's effect on its intended reader.
